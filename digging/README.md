# 🚜 Digging - Standalone CGA Arcade

Faithful recreation of the iconic 1983 Windmill Software CGA digging classic built with HTML5 Canvas, Web Audio PC-speaker synthesis, and native JavaScript.

## Features
- 15x10 CGA classic arcade experience.
- Dynamic dirt excavation and emerald collection (with streak bonuses).
- Gold bag gravity and physics: drop bags to crush Nobbins/Hobbins or break open into coins.
- Nobbins and mutating Hobbins.
- Recharging laser weapon (`Space` / `F1` / `FIRE` button).
- Bonus Cherry mode with the "William Tell Overture" and edible monsters.
- PC speaker 1-bit synthesized audio ("Popcorn", "William Tell", "Funeral March").

## Quick Start
```bash
npm start
# or
node server.js
```
Open [http://localhost:8882](http://localhost:8882) in your browser.
