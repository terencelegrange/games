# 🟡 Maze Arcade - Standalone Arcade

Authentic retro maze running classic built with HTML5 Canvas, Web Audio API, and native JavaScript.

## Features
- 28x31 classic arcade maze faithfully recreated.
- 4 distinct Ghost AIs:
  - **Blinky** (Red): Direct chaser.
  - **Pinky** (Pink): Ambusher (targets ahead).
  - **Inky** (Cyan): Flanker (mirrored vector).
  - **Clyde** (Orange): Shy wanderer.
- Scatter, Chase, and Frightened ghost states with flashing blue edible states.
- 8-bit sound effects synthesized via Web Audio API.
- Responsive D-pad controls and keyboard navigation.

## Quick Start
```bash
npm start
# or
node server.js
```
Open [http://localhost:8881](http://localhost:8881) in your browser.
