# 🧱 Blockz - Standalone Arcade

Faithful recreation of the iconic tile-matching puzzle classic built with HTML5 Canvas, Web Audio sound synthesis, and native JavaScript.

## Features
- Standard 10x20 well playfield with 7 canonical tetrominoes (I, J, L, O, S, T, Z).
- 7-bag randomizer and Super Rotation System (SRS) wall kicks.
- Ghost piece projection.
- Hold queue (`C` / `Shift`) and Next piece previews.
- Soft drop (`↓`) and instant Hard drop (`Space`).
- Web Audio synthesizer: rotation clicks, soft drops, line clears, and Tetris 4-line chord.

## Quick Start
```bash
npm start
# or
node server.js
```
Open [http://localhost:8883](http://localhost:8883) in your browser.
